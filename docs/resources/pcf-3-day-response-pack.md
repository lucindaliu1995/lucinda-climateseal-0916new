# PCF 3-Day Response Pack

## A practical pack for manufacturers responding to a customer PCF request

**Use this pack when:** a customer asks for a product carbon footprint and gives you a short deadline.

**The goal:** send a transparent preliminary response in three days, then improve it with better data.

**Important:** a three-day preliminary response is not automatically an ISO 14067-compliant final report, a certification, or an independently verified result. State the status clearly.

---

## 1. Customer clarification email

Copy, adapt, and send this before collecting data.

**Subject:** Clarifying the PCF information requested for [Product / Model]

Hello [Name],

Thank you for your request for the product carbon footprint of [Product / Model]. To provide a result that is useful and comparable for your review, could you please confirm the points below?

1. **Product and unit:** Do you need the result per item, per kilogram, per tonne, or per order?
2. **Included stages:** Should we include raw materials, inbound transport, manufacturing, packaging, delivery, product use, and end of life? Please tell us which stages are required.
3. **Production site and period:** Which site and reporting period should the result represent?
4. **Output format:** Do you need one preliminary number, a calculation file, a methodology note, a customer questionnaire, or a formal report?
5. **Evidence requirement:** Are supplier-specific data, a named database, a product category rule, or independent verification required?
6. **Deadline and use:** Will the result be used for internal screening, supplier comparison, a tender, a public claim, a contract, or another purpose?

Once we have this information, we will confirm the calculation scope, the data available, and the timing for a preliminary response.

Best regards,

[Name]  
[Role / Company]

---

## 2. PCF data collection checklist

Start with the items most likely to change the result. Mark each item as **ready**, **requested**, or **not applicable**.

### Product and materials

- [ ] Product model, version, and description
- [ ] BOM, recipe, or product specification
- [ ] Material names, grades, weights, and units
- [ ] Product quantity and production period
- [ ] Scrap, yield, and production loss
- [ ] Recycled content and supporting evidence

### Factory and production

- [ ] Electricity use for the reporting period
- [ ] Natural gas, steam, fuel, or other energy use
- [ ] Production volume for the same period
- [ ] Method for assigning shared factory energy to this product
- [ ] Direct process emissions, if relevant
- [ ] Packaging and internal transport

### Suppliers and logistics

- [ ] Supplier-specific carbon data, if available
- [ ] Supplier production data or material activity data
- [ ] Material origin and supplier location
- [ ] Transport mode, distance, and shipped weight
- [ ] Recycled-material or other environmental claim evidence

### Calculation record

- [ ] Product unit is written clearly
- [ ] Included and excluded life-cycle stages are written clearly
- [ ] Reporting period and geography are recorded
- [ ] Each input has a source and unit
- [ ] Each conversion factor has a source, version, geography, and unit
- [ ] Assumptions, estimates, exclusions, and open requests are recorded

## 3. Three-day response-pack structure

### Day 1 - Clarify and scope

- Confirm the product, unit, production site, reporting period, included stages, intended use, and evidence requirement.
- Write one scope sentence:

> We will estimate emissions for [Product], per [unit], made at [Site] using [period] data, covering [included stages]. The first response is for [intended use]. [Supplier data / independent review] is [complete / pending].

- Create a data request list and assign an owner to each missing item.

### Day 2 - Calculate and document

- Calculate the best available first estimate.
- Separate company or supplier records from industry or database reference data.
- Record assumptions, exclusions, data gaps, conversion factors, and unit conversions.
- Use a range or a clearly labelled preliminary result when important data is missing.

### Day 3 - Review and send

Prepare a concise three-to-five-page response pack:

1. **Executive result:** product, unit, included stages, period, and preliminary result.
2. **Method summary:** materials, energy, transport, packaging, allocation, and calculation approach.
3. **Data-source register:** actual company or supplier records versus reference data.
4. **Gap and risk list:** missing evidence, estimates, exclusions, and high-impact uncertainties.
5. **Next-step plan:** data owner, action, target date, and review or verification requirement.

## 4. BOM readiness checklist

### A BOM is usually enough to start a material-stage estimate, but not enough to claim a complete PCF.

Score each item:

| Check | Yes | No | Notes |
| --- | :---: | :---: | --- |
| Product model and revision are confirmed | [ ] | [ ] | |
| Every material has a weight and unit | [ ] | [ ] | |
| Material grades or specifications are known | [ ] | [ ] | |
| Production loss or scrap is known | [ ] | [ ] | |
| Recycled content is supported by evidence | [ ] | [ ] | |
| Factory energy can be linked to the product | [ ] | [ ] | |
| Supplier or material origin is known | [ ] | [ ] | |
| Transport and packaging information is available | [ ] | [ ] | |
| The customer-required calculation stages are covered | [ ] | [ ] | |

### How to interpret the result

- **7-9 Yes:** ready for a structured first PCF calculation; verify the high-impact inputs.
- **4-6 Yes:** ready for a preliminary estimate with a clear gap list.
- **0-3 Yes:** use the BOM to define the project and request more data before presenting a product-level result.

Never convert a BOM-only material estimate into a complete product carbon footprint without stating what is missing.

## 5. Preliminary estimate wording

Use language that matches the evidence available.

| Avoid | Use instead |
| --- | --- |
| “This product emits 2.34 kg CO2e.” | “Preliminary estimate: 2.34 kg CO2e per product under the stated boundary and assumptions.” |
| “ISO 14067 certified.” | “Prepared with reference to ISO 14067; independent review has not been completed.” |
| “Supplier-specific footprint.” | “Estimate based partly on secondary reference data; supplier-specific information is pending.” |
| “Complete product carbon footprint.” | “The estimate covers [stages] and excludes [stages].” |
| “Accurate carbon number.” | “Best available estimate based on the data listed in the source register.” |

### Customer-ready email wording

> Attached is our preliminary product carbon footprint estimate for [Product], calculated per [unit] and covering [included stages]. The estimate uses [company / supplier data] and documented reference data where supplier-specific information is pending. The attachment lists the calculation boundary, assumptions, exclusions, data sources, and open requests. Independent verification has not yet been completed.

---

## Final send checklist

- [ ] Product and unit are unambiguous
- [ ] Included and excluded stages are stated in plain language
- [ ] Production site, geography, and period are recorded
- [ ] Actual and reference data are separated
- [ ] Conversion-factor sources and versions are recorded
- [ ] Assumptions, estimates, and data gaps are visible
- [ ] Review status and next update date are included
- [ ] The wording does not imply certification or verification that has not happened
